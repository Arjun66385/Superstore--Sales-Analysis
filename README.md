# Superstore Sales Data Analysis

## About the Project
This project explores the Superstore sales dataset using Python to identify sales trends, profitability, and business insights.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset Overview
- **Total Records:** 9,994
- **Total Columns:** 21
- **Missing Values:** 0
- **Duplicate Rows:** 0

## Key Performance Indicators
| Metric | Value |
|---|---:|
| Total Sales | $2,297,200.86 |
| Total Profit | $286,397.02 |
| Total Orders | 5,009 |
| Total Quantity Sold | 37,873 |

## Key Insights
- Technology is the highest-selling category.
- Technology generates the highest profit among the three categories.
- The West region has the highest regional sales and profit.
- California has the highest sales among states.

## Conclusion
The analysis highlights differences in sales and profitability across product categories and regions. These findings can help businesses better understand performance and identify opportunities for improvement.
